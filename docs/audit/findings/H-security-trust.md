## 3. Specifications

### 3.1 Recommended `public/_headers` block (all HTML)

Keep the existing rules (`/opengraph-image`, the immutable caches) and add the block below **once**. Every line is under Pages' 2,000-character limit, and Pages allows up to 100 rules. HSTS goes on the Cloudflare zone (SEC-08), not here.

```
/*
  X-Content-Type-Options: nosniff
  Referrer-Policy: strict-origin-when-cross-origin
  X-Frame-Options: DENY
  Cross-Origin-Opener-Policy: same-origin
  Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=(), serial=(), hid=(), bluetooth=(), midi=(), display-capture=(), browsing-topics=(), accelerometer=(self "https://www.youtube-nocookie.com"), gyroscope=(self "https://www.youtube-nocookie.com"), autoplay=(self "https://www.youtube-nocookie.com"), encrypted-media=(self "https://www.youtube-nocookie.com"), picture-in-picture=(self "https://www.youtube-nocookie.com"), fullscreen=(self "https://www.youtube-nocookie.com"), clipboard-write=(self "https://www.youtube-nocookie.com"), web-share=(self "https://www.youtube-nocookie.com")
  Content-Security-Policy-Report-Only: <Stage 0 policy from §3.2>

/.well-known/security.txt
  Content-Type: text/plain; charset=utf-8
```

Notes:

**Stage 1 policy (enforced in `csp-test.mjs stage1`: 0 violations).** The flows covered were home, Accept GA, `/indices/blokc5`, `/token` (live supply read), `/about` plus Play, `/governance`, `/legal/cookie-policy`, 404, and a client-side navigation to `/security`.

```
default-src 'self'; script-src 'self' 'unsafe-inline' https://www.googletagmanager.com; style-src 'self' 'unsafe-inline'; img-src 'self' https://img.youtube.com https://*.google-analytics.com https://*.googletagmanager.com; font-src 'self'; connect-src 'self' https://arb1.arbitrum.io https://*.google-analytics.com https://*.analytics.google.com https://*.googletagmanager.com; frame-src https://www.youtube-nocookie.com https://www.youtube.com; object-src 'none'; base-uri 'self'; form-action 'none'; frame-ancestors 'none'; upgrade-insecure-requests
```

(about 610 characters; under the 2,000-character line limit)

**Why not hashes in the header?** Each page needs 29–108 hashes, about 1.7–5.8 kB, which exceeds Cloudflare Pages' **2,000-character `_headers` line limit**. Nonces need per-request rendering: a Pages Function or Worker with HTMLRewriter would turn every page into a Function invocation, and `_headers` doesn't apply to Function responses. Next's experimental `sri` covers external chunks only, not inline flight scripts.

**Rollout:**
1. **Stage 0 (week 1): Report-Only.** Ship the Stage 1 policy as `Content-Security-Policy-Report-Only`, *without* `upgrade-insecure-requests`, which browsers ignore in report-only mode and warn about. Add a reporting endpoint (`report-to` + `Reporting-Endpoints`). **Owner decision:** use a 20-line Worker that logs without storing IPs, or no endpoint plus the Playwright harness as a CI gate. A third-party collector would be a new processor and would have to be listed in the Privacy Policy.
2. **Stage 1 (week 2): enforce** the same policy as `Content-Security-Policy`. This already adds `frame-ancestors`, `object-src`, `base-uri`, `form-action` and host-locked `script-src`, `connect-src` and `frame-src`.
3. **Stage 2 (when convenient): hash inline scripts.** Add a `postbuild` script that walks `out/**/*.html`. For each page it computes the sha256 of every inline script (skipping `application/ld+json`) and injects `<meta http-equiv="Content-Security-Policy" content="script-src 'self' <hashes> https://www.googletagmanager.com">` immediately after `<head>`. The header keeps `'unsafe-inline'`, because the header can't carry hashes and both policies must pass. The *intersection* is then effectively hash-only. **Verified (`csp-test.mjs stage2`):** 0 violations on every flow above, and an injected inline `<script>` was **blocked** (`script-src-elem`). Caveats: a meta CSP can't carry `frame-ancestors` or reporting, so those stay in the header. Home HTML grows by about 6 kB raw (random hashes compress poorly; flagged to E). Make the post-build step part of `npm run build` so a forgotten step can't ship pages without meta.
4. **Regression gate:** add `tools/agent-H/csp-test.mjs` (or an equivalent) to the Phase 4 checks. Any new third party (Cloudflare Web Analytics, Zaraz, Turnstile, Intercom and so on) needs a CSP and Privacy Policy update in the same PR.
