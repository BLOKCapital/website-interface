# A · UX & Information Architecture

Auditor: Agent A · Snapshot `redesign` @ `5beb0ee` · 2026-10-11

## 1. Scope & method

- **Code read:** `src/lib/nav.ts`, every `src/components/nav/*`, `Footer`, `PageHero`, `CtaBand`, `Button`, `ArrowLink`, every route in `src/app/**`, every home section, the explainers (`ProtocolExplorer`, `RulesDemo`, `HowItWorksScroller`/`GardenMock`, `IndexShowcase`, `IndexExplorer`, `RebalanceLab`, `AllocationExplorer`, `DecisionPipeline`), the live stack (`useLive`, `rpc`, `feeds`, `prices`, `LiveStatus`, `TokenContract`) and the proposal snapshot (`proposals.ts`, `ProposalBoard`, `ProposalList`).
- **Browser (Playwright, headless Chrome):** I measured the section outline and heading tree at 375 and 1280. A link crawl covered all 15 routes: every hash link was checked against the target page's ids, and every external link was checked for `target` and a visible cue. I clicked through flows F1–F8, including hash links reached by client-side navigation. For live data, I intercepted `arb1.arbitrum.io` four ways: blocked, hung for 20 s, offline, and failing after a good read (clock fast-forwarded about 3 min). I also tested a single feed failing inside an otherwise good batch. Autoplay was tested with taps on a 375 touch context.
- **Server note:** the shared `:4173` server crashed partway through the audit (`scratchpad/serve.log`: `EMFILE: too many open files`). I did not restart it. I served the same `baseline-src/out` read-only on a private port, `:4181`, then stopped it. Results are the same build.
- Screenshots used: `baseline/screenshots/home_375.jpg` (cropped), `this-page-does-not-exist_1280.jpg`, `governance_1280.jpg`, plus my own in `scratchpad/tools/agent-A/shots/` (`f2-howitworks-landing-1280.png`, `f1-mobile-sheet-375.png`, `anchor-yield.png`, `state-blocked-*.png`, `menu-*.png`).
