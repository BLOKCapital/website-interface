# E: Performance & Core Web Vitals

Auditor: Agent E · `redesign` @ `5beb0ee` · 2026-10-11

## 1. Scope & method

- **What I checked:** LCP mechanics, fonts, render-blocking CSS, hydration/INP, HTML/RSC weight, images, JS/CSS chunks, caching/compression, prefetch, live polling and idle animation cost.
- **Sources:** code review; the baseline Lighthouse JSONs; the build output in `scratchpad/baseline-src/.next` (I parsed each chunk into its modules with acorn); and production response headers from `curl https://blokcapital.io`, which currently serves an older build.
- **Servers:** measurements ran against my own `serve` of the **same baseline export** on `:4195`, because `:4173` was down (EMFILE) when I started.
- **Experiments:** I built three variants in an isolated scratch copy (`scratchpad/agent-E-variant`, never the repo), served on `:4196`–`:4198`:
  - **V1** = the PERF-01, PERF-02 and PERF-05 fixes.
  - **V2** = V1 + `experimental.inlineCss`.
  - **V3** = V1 + `<Suspense>` around each home section.
- **Lab profile:** "lab" means Playwright with Chrome, a 412×823 viewport at DPR 1.75, 4× CPU via CDP, and 1.6 Mbps / 150 ms RTT applied throttling. I took the median of 3–7 runs, plus Lighthouse 12.2.1 (simulated and `--throttling-method=devtools`). Latency comes from the Event Timing API.
- **Measurements are relative.** The machine is shared, with load average 3–35 during the runs. Scripts are in `scratchpad/tools/agent-E/`: `lcpab.mjs`, `lcpsrv.mjs`, `profile.mjs`, `inp.mjs`, `earlytap.mjs`, `anim*.mjs`, `idle.mjs`, `prefetch.mjs`, `domcost.mjs`, `fontuse.mjs`, `html.mjs`, `chunks.mjs`, `clssrc.mjs`, `lhrun.sh`.

## 4. Performance constraints for Agent C (motion), hard rules

- **R1. The LCP candidate must be visible at first paint.** This means the largest above-the-fold text block or image at 375–1440 px: the hero and PageHero lead paragraph on mobile, the h1 on desktop `/about` and `/token` (measured), the desktop home render, and the `/token` token image.
  - At the first frame it must have opacity 1, no `animation-delay`, no clip-path or mask reveal, no `visibility:hidden`, and no blur.
  - Allowed: transform-only motion (translate ≤ ~12 px or a subtle scale) that starts at opacity 1, and any motion on siblings that are not the LCP (eyebrow, badge, CTAs, chips, flow lines).
  - The "opacity 0.01" trick is not allowed: it games the metric without fixing what people see.
  - **Gate:** LCP − FCP ≤ 50 ms on every hero page at 412 px, 4× CPU, 1.6 Mbps / 150 ms (`lcpsrv.mjs`).
- **R2. Word-by-word h1 reveals (`.split-load`, opacity 0 + 6 px blur).** They only "pass" today because the whitespace text nodes between the word spans paint immediately. Where the h1 is the LCP (desktop `/about`, `/token`), treat it under R1.
- **R3. Infinite loops:**
  - Use composited properties only: `transform` and `opacity` on HTML elements. No `stroke-dashoffset`, SVG-child transforms, `box-shadow`, `border-color` or `background-color` loops.
  - Pause them off-screen (PERF-04 mechanism) and under reduced motion.
  - At most about 4 running in the viewport.
  - Gate: idle main thread < 5 % at 4× CPU when no loop is in view (`anim2.mjs`).
- **R4. JS-driven motion.** Canvas, rAF and setState-per-frame effects (`useTween`, CountUp, Scramble, RulesDemo typing at 24 ms) start only in view and stop off-screen. Prefer CSS. Add no new client islands or libraries for motion.
- **R5. Interactions.** Keep every post-load interaction under 100 ms at 4× CPU (today 24–72 ms). Avoid animating `grid-template-rows` or height on large subtrees during interactions.

## 6. Keep

- Static export on Cloudflare Pages with brotli, HTTP/3, immutable `/_next/static`, and Early Hints from Pages.
- `next/font` self-hosting, latin-only preloads, size-adjusted fallbacks, and `display: swap`.
- Mono not preloaded.
- Visibility- and viewport-gated live polling with backoff and honest states (`useLive.ts`). The RPC preflight is cached for 600 s.
- The YouTube click-to-play facade, and GA loaded only after consent with no preconnect before consent.
- CSS-first motion, a working reduced-motion path, and `RevealScript` running before hydration (cheap: about 5 ms at 4×).
- Pre-built garden width variants, which work without Image Transformations.
- Fast post-load interactions (24–72 ms at 4×), CLS ≈ 0 on fast networks, and Lighthouse BP/SEO at 100.
